# Original shop sound cues

Original mono 22050 Hz / signed 16-bit PCM tones, synthesized locally from sine
fundamentals plus a quiet second harmonic, with 8 ms attack / 35 ms release.
No third-party recordings, downloads, fonts or network service. Recipe is recorded
in tests/generate_audio.py. Durations 55–300 ms; sample peak below 0.28. Runtime
plays them quietly through at most four reusable voices, with a persistent mute.
